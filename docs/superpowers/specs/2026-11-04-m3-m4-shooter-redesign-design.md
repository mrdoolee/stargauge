# 미션 3·4 슈팅 재설계 + 미션 1 조정 — 설계

작성일: 2026-11-04
상태: 교사 승인("좋아. 그렇게 하자", "개발 시작")
상위 문서: `docs/superpowers/specs/2026-11-03-patterns-art-briefing-design.md`, `docs/superpowers/specs/2026-10-30-star-color-shooter-design.md`. 이 문서와 다르면 이 문서를 따른다.

## 1. 의도

교사가 플레이해 보고 말했다: "앞에 라운드는 슈팅게임 느낌인데, 3라운드 4라운드는 전혀 슈팅게임의 재미 요소가 없어." 3·4라운드는 별자리·성단이 거의 제자리에 떠 있고 몇 개만 골라 쏘는 퍼즐이다. 몰려오는 적, 피하기, 격추하는 손맛이 없다.

교사 결정:
- 오리온자리 실제 별(리겔·시리우스·베텔게우스)과 보석상자 성단은 **남기지 않아도 된다**.
- 별이 아닌 **적(방해 드론, 보스 함선)**을 넣어 격추하는 손맛을 살린다. 학습과의 연결은 아래 "별빛 충전 빔".
- 1라운드: 흰색만 나와서 재미없다 → 다른 색 쇳물도 함께 떨어지고, **흰색만 점수**. 다른 색을 쏘면 **선체 온도 벌칙**. 연습 시간은 **더 짧게**.

## 2. 목표 / 비목표 / 안티목표

**목표**
- 3·4라운드가 1·2라운드처럼 계속 쏘고 피하는 슈팅 게임이 된다.
- 학생은 "어떤 별로 충전할까"를 **색으로만** 판단해야 이긴다. 크고 밝은 적색 별로 충전하면 약해서 진다 → "크기·밝기 ≠ 온도"를 몸으로 겪는다.
- 1라운드 화면에 여러 색 쇳물이 섞여 판단할 거리가 생긴다.

**비목표**
- 새 미션 추가, 퀴즈(귀환 보고서) 문항 변경, 브리핑 화면 구조 변경, 난이도 체계(긴장도·속도 띠·반응 시간 하한) 변경.

**안티목표 (이러면 실패)**
- 별을 파괴하는 연출 (그대로 금지). 별은 쏘면 '측정'되고 충전만 해 준다. **드론과 보스 함선은 별이 아니므로 격추·폭발해도 된다.**
- 충전 세기가 별의 크기·밝기에 따라 달라지는 것. 충전은 **색 7단계로만** 정한다.
- 방어막·장갑 색이 교과서 7색과 다르게 보이는 것 (코드로 정확한 팔레트 색을 입힌다).
- 드론·보스 탄이 반응 시간 하한·안전 거리 규칙을 어기는 것.
- 쉬움에서 학생이 끝까지 못 가는 것.

## 3. 별빛 충전 빔 (3·4라운드 공통 규칙)

- 우주선 빔에는 **충전 단계**가 있다. 시작은 충전 없음(가장 약함).
- 별을 맞히면 그 별을 '측정'하고(지금처럼 표시 고리 + 사라짐 연출, 파괴 아님) 충전 단계를 **그 별의 색 단계로 바꾼다**. 청색 = 가장 셈(7), 청백색 6, 백색 5, 황백색 4, 황색 3, 주황색 2, 적색 1. 크기·밝기 무관.
- 충전은 다음 별을 측정할 때까지 유지된다. 드론·보스를 쏘아도 줄지 않는다. (제 판단: 단순하게.)
- HUD 위쪽 스타게이지에서 **현재 충전 색 칸을 강조**하고 "빔 충전" 라벨을 붙인다(게이지 순서 = 교과서 그림 8-5).
- 빔 색도 충전 색을 따라 바뀐다(정확한 팔레트 색).
- 드론·보스 장갑에는 **방어막 색**이 있다. 빔 충전 단계 ≥ 방어막 색 단계면 뚫린다(명중). 아니면 튕긴다: 짧은 튕김 연출 + 첫 몇 번은 안내("빔이 약해요. 더 뜨거운 색의 별로 충전하세요.").
- 첫 번째로 적색·주황색 큰 별을 측정했을 때 한 번 안내: "크고 밝아도 적색이면 온도가 낮아요 → 약한 충전".
- 별에 부딪히면 색에 따라 선체 온도가 오르는 규칙은 그대로. 드론·보스 탄에 맞으면 일정량(소행성과 같은 값, 난이도 배율 적용).

## 4. 미션 3 — 밝기의 함정 (새 설계)

- 별이 편대로 흘러온다(기존 편대 시스템). 일부러 **크고 눈부신 적색·주황색 별이 자주**, 작고 흐린 청색·청백색 별은 드물게 나온다(색 비율은 빌더가 조정, 단 청색 계열이 너무 안 나와 막히지 않게 "필요한 색 보장" 규칙 적용).
- **방해 드론**이 편대로 들어와 화면 위쪽을 오가며 탄을 쏜다. 드론마다 방어막 색이 있고, 대부분 **백색 이상**이 필요하다(쉬움은 황백색 이상도 섞음 — 제 판단).
- 목표: 드론을 정해진 수만큼 격추(시작값 쉬움 5 / 중간 6 / 어려움 8 — 제 판단, 빌더 조정). 남은 목표는 HUD에 표시.
- 별점: 튕긴 횟수(약한 충전으로 쏜 횟수)를 기존 오답 횟수 자리에 쓴다.
- 클리어 정리 카드: "크고 밝아도 적색 별은 차가워요. 온도는 색으로 비교해요." (기존 m3 카드 문구 유지 가능)
- 오리온자리 묶음, 함정 경로 계산, 완성 그림 화면은 **제거**.

## 5. 미션 4 — 보스전 (새 설계)

- **보스 함선**(별 아님)이 화면 위쪽에 나타난다. 3단계, 단계마다 장갑판 색이 오른다: 1단계 황백색 이상, 2단계 백색 이상, 3단계 청백색 이상(제 판단; 쉬움은 한 단계 낮춤 가능).
- 단계마다 보스 체력이 있고, 충분한 충전으로 명중시키면 줄어든다. 체력이 0이면 다음 단계, 3단계까지 끝나면 보스 퇴각(격추 연출) → 클리어.
- 보스는 기존 보스 주기(공격 → 빈틈)를 쓴다: 공격 때 부채꼴·조준 탄, 빈틈 때 약점이 열린 듯한 연출과 "지금이 기회!" 안내. 탄은 안전 거리·반응 시간 하한·몸풀기 규칙을 지킨다(기존 boss.js 재사용).
- 그 사이 충전용 별이 편대로 흘러온다(청색 계열 보장).
- 제한 시간 `M4_TIME_LIMIT_SEC`(210초) 그대로. 시간이 끝나면 실패가 아니라 "보스가 도망갔어요" 정리 후 다음으로.
- 끝의 질문 2개를 새 이야기로 바꾼다(제 판단):
  1. "가장 강한 충전을 주는 별의 색은?" → 청색
  2. "크고 밝은 적색 별로 충전하면 빔이 약했던 이유는?" → 적색 별은 표면 온도가 낮아서 (오답: 크기가 커서 / 밝아서)
- 결과 막대그래프: 4라운드에서 **측정한 별의 색별 개수**(기존 성단 막대그래프 자리).
- 보석상자 성단 배치, 적색 초거성 보스 별, 성단 흔들림은 **제거**. NOIRLab 크레디트 문구도 쓰지 않으면 제거.

## 6. 미션 1 — 용광로 탈출 조정

- 연습 시간 `M1_PRACTICE_SEC` 30초 → **15초**(제 판단).
- 쇳물 덩어리가 **여러 시작 색**으로 떨어진다: 흰색 약 40%, 나머지(노·주·붉)가 섞임(제 판단, 빌더 조정). 떨어지며 식는 규칙은 유지(시작 색에서 계속 식음).
- 흰색(또는 흰색이 끝난 지 `M1_WHITE_GRACE_MS` 이내)만 정답·점수. 다른 색을 쏘면 오답: 짧은 안내 + 선체 온도 벌칙(`WRONG_SHOT_HEAT`). 연습 구간은 지금처럼 벌칙 없음.
- 흰색이 너무 드물어 목표(8개)를 못 채우는 일이 없게, 흰색 시작 덩어리를 일정 개수 안에 반드시 넣는다(필요한 색 보장과 같은 방식).

## 7. 화면·그림

- 새 그림(스타일 A, OpenAI API, `tools/gen-images.mjs`): 방해 드론 1~2종, 보스 함선 1종(단계별로 같은 그림 + 코드 장갑 색). 별 7색 주색 금지, 글자 금지.
- 방어막·장갑의 색 표시는 **코드로** 팔레트 색을 입힌 고리·판(색 정확성). 탄은 코드 그림.
- 브리핑 m3·m4 문구를 새 규칙에 맞게 바꾼다(정답을 직접 말하지 않음). 브리핑 그림 m3(크고 붉은 별 + 작고 푸른 별)는 그대로, m4(우주선 + 성운)도 그대로 써도 된다.
- 결과 화면의 오리온자리 그림을 **완성 스타게이지 + 측정 색 막대그래프**로 바꾼다(제 판단).
- 마지막 퀴즈 3번(베텔게우스)은 교과서 내용이므로 그대로 둔다.

## 8. 그대로 두는 것

긴장도·속도 띠·반응 시간 하한·안전 거리·몸풀기·편대 시스템, 선체 온도 색 순서, 브리핑 구조, 귀환 보고서 퀴즈, 난이도 3단계, 쉬움 15분 목표.

## 9. 빌더에게 맡기는 것

드론 움직임·탄 패턴 세부, 방어막 색 분포, 목표 수, 보스 체력, 충전 HUD 세부, 튕김 연출, 색 비율, 테스트 수치.

## 10. 제 판단으로 정한 것 (교사 확인용)

충전은 다음 측정까지 유지 · 쉬움 방어막 일부 황백색 · 목표 드론 수 5/6/8 · 보스 장갑 단계 황백→백→청백 · m4 질문 2개 교체 · 결과 화면 그림 교체 · 연습 15초 · 흰색 시작 40% · 퀴즈 3번 유지.
